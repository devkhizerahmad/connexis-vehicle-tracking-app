5-step debug routine

  1. Error ka pehla line copy (RedBox/logcat).
  2. Stack me apni repo ki pehli file — wahi culprit.
  3. S5 table se file ka kaam ka context lo.
  4. Gates: npx tsc --noEmit + npx eslint src --quiet + npx jest.
  5. UI change hua → UI-FREEZE procedure (neeche).

UI-FREEZE overlay procedure

  1. adb shell screencap -p /sdcard/cur.png && adb pull /sdcard/cur.png — device 780×1688 @2x = 390×844dp, right-edge stride artifact exclude (x ≥ 374).
  2. Reference: /ui-baseline/ — full (details_full.png, profile_full.png) + S3 crops.
  3. Pass rule: crop ke andar 0 differing content rows (OS clock allowed).
  4. ❄ value change hui → baselines + baseline_record.json usi task me naye SHA-256 ke saath.

Case study — splash black-frame (real bug, fixed)

  • Symptom: logo splash ke baad Home se pehle ~1-5 frames black.
  • Cause: setTimeout(2400) splash unmount karta tha, phir RootNavigator (5 tabs) pehli baar mount — init frames me screen khali + Android default windowBackground black.
  • Fix: navigator immediately mount + splash overlay ON TOP; dismiss onReady && ≥2400ms par 300ms native fade; native safety net windowBackground=#F8F3F3 — App.tsx · styles.xml · colors.xml.
  • Lesson: conditional if (ready) return <Navigator/> navigation init me blank window deta hai — overlay pattern use karo.
