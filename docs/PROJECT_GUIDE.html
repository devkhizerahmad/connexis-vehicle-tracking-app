S0 — AI-Agent Quick Context (sirf ye box parh kar kaam shuru kren)

  1. Stack: bare React Native CLI + Hermes, TypeScript. Entry: index.js → App.tsx.
  2. Architecture: feature-first — src/features/* (screens+components+hooks+services+mocks), src/shared/* (reusable), src/navigation/*.
  3. Path aliases: @shared/*, @features/*, @navigation/* — babel.config.js + tsconfig.json me hamesha dono sath edit kren.
  4. Boot: RootNavigator pehle frame pe mount (ek baar), SplashOverlay upar fade hota hai (onReady && ≥2400ms), native safety-net windowBackground #F8F3F3.
  5. Tabs (custom BottomNav): Home, Report, Engine Control, Map, Profile. Built screens: Details (HomeStack), Profile (ProfileStack). Baqi shells.
  6. UI-FREEZE contract: approved screens pixel-frozen; baselines ui-baseline/baseline_record.json + 16 PNGs; compare 390×844dp, right-edge stride x≥374 exclude.
  7. Performance contract G1–G10: memo/useCallback/useMemo, FlatList rules, useNativeDriver, StyleSheet.create, zero console.log — gate results har task me report.
  8. Styling: theme tokens → styles.ts (StyleSheet.create); JSX me static inline style = 0; hex sirf src/shared/theme/ me.
  9. Data: screen → hook → service → mock JSON (API-ready signatures); screens mocks directly import nahi karti.
  10. Docs rule: koi bhi structural change = dono guide files usi task me update.

      ├─ RootNavigator (mounts immediately, once) ──> Tab.Navigator (5 stacks)

S9 — Debugging Guide

npx react-native start --reset-cache     # Metro + cache clear
npm run android                          # build+run (native changes ke liye zaroori)
adb reverse tcp:8081 tcp:8081            # device → Metro
adb logcat | grep ReactNativeJS          # runtime logs
adb exec-out screencap -p > shot.png     # baseline-class screenshot
# Windows stale cache: Task Manager → sab node.exe kill → dobara start
Red-screen typePehchanFix order
UnableToResolveError (HTTP 500)alias/module not found1 alias babel+tsconfig dono · 2 extensions list (.ts,.tsx,…) · 3 --reset-cache · 4 node.exe kill
Runtime TypeErrorstack trace me pehli app-file line aap ki haifile:line kholen → last change recall → guard/optional chain
Yellow warningsnon-fataldeprecated API/deps update; ignore if documented
  1. Error header parho (type identify).
  2. File:line kholen.
  3. Last change yaad kren (diff soch).
  4. Cache reset + restart.
  5. Logs ke sath reproduce kren.
UI-FREEZE check: 390×844dp screenshot len → ui-baseline/ PNGs ke sath overlay (full + crops); right-edge stride x≥374 exclude; koi diff = task fail. Case study: black flash = splash unmount → navigator init gap → default black windowBackground; fix = overlay+onReady fade + windowBackground #F8F3F3 (S1).
